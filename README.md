# 時刻（jikoku）

複数のカメラの時計ずれを後で合わせるための「写真版カチンコ（映画撮影で使う拍子木）」。
iPhone に時分秒を大きく表示し、それを各カメラで撮っておく。後で写真に写った時刻と、写真に記録された撮影時刻（Exif）の差を見て補正する。

作成: 2026-09-27。作り方は `work/副業/apps/README.md` の標準手順（PWA＝iPhone のホーム画面に置けるウェブアプリ → GitHub Pages）どおり。

## できること

- 日付（YYYY-MM-DD）と時刻（HH:MM:SS、24時間表記）を表示。縦持ち・横持ちどちらでも画面幅いっぱいに広がる（横持ちの方が大きい）
- 白地に黒の太字、数字の幅をそろえた書体 → 人にも AI にも読み取りやすい
- 秒の変わり目ぴったりに切り替わる
- 画面が暗くならないようにする（対応している iPhone のみ。効かないときは画面をタップ）
- 電波がなくても開ける

## 使うときのコツ

- iPhone の時計は自動で正しい時刻に合わせられている（設定 → 一般 → 日付と時刻 →「自動設定」がオン）ことが前提。
- 1台のカメラにつき、撮影の最初（できれば最後にも）1枚ずつ撮っておくと、途中で時計がずれていっても分かる。
- シャッターが秒の切り替わりの瞬間に当たると、1秒の誤差は出うる。
